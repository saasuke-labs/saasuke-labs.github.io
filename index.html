The tools

Three projects, one publishing workflow

Each one is a single Go binary with no runtime to install. Docs live with each project and are published here.

Gengo

Static site generator

Turns Markdown, HTML templates and one YAML manifest into a static site. This site is built with it.

  • Pages rendered in parallel, with a plain mode for CI
  • Diagrams and charts in Markdown through Nagare
  • Pull data from any HTTP API at build time
$ gengo generate
$ gengo serve --watch
Docs GitHub Changelog

Nagare

Diagrams as code

A small text language that renders architecture diagrams and charts to SVG, so they live in version control next to the code.

  • Use it as a CLI, an HTTP server or a Go library
  • One visual system for every component
  • Transparent canvas that sits on any page background
web:Browser(text: "Shop")
api:Server(title: "API")

web.e --> api.w
Docs GitHub Changelog

Kotomi

Comments for static sites

Comments and reactions for pages that have no backend. Run one container, embed a widget, moderate from an admin panel.

  • Self-hosted, with SQLite or Firestore storage
  • Several sites managed from one instance
  • Optional AI-assisted moderation
$ docker build -t kotomi .
$ docker run -p 8080:8080 kotomi

03 · DISCUSS
